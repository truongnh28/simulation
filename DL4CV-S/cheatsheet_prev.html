CNN — Tất Cả Công Thức & Bài Tập Mẫu

1. Định Nghĩa: Cross-Correlation vs Convolution

Cross-Correlation (PyTorch "Conv2d" thực ra dùng cái này — không flip W):
$Y(u,v)=\sum_{i=-r}^{r}\sum_{j=-r}^{r}X(u+i,\,v+j)\cdot W(i,j)$
Convolution thực sự (flip W 180° trước rồi cross-corr):
$Y(u,v)=\sum_{i=-r}^{r}\sum_{j=-r}^{r}X(u-i,\,v-j)\cdot W(i,j)$
$r=\lfloor k/2\rfloor$; quan hệ: Conv$(W)$ = XCorr$(\text{Rot}_{180°}(W))$

2. Multi-channel Input (D channels)

Kernel phải cùng D channels với input; tổng hợp → 1 feature map:
$Y(u,v)=\sum_{c=1}^{D}\sum_{i=-r}^{r}\sum_{j=-r}^{r}X_c(u+i,v+j)\cdot W_c(i,j)$
$K$ filters → concat → output $\in\mathbb{R}^{o_1\times o_2\times K}$

3. Kích Thước Output (công thức chung)

$o=\lfloor(i+2p-k)/s\rfloor+1$   (áp cho mọi Conv và Pool)
Chế độpo (s=1)Ghi chú

MaxPool no-pad: $o=\lfloor(i-k)/s\rfloor+1$;   MaxPool 2×2 s=2: $o=i/2$

Bài 3 — Conv vs FC: Tại sao CNN hiệu quả?

Conv(28×28×32→64, k=3, p=1, s=1): Params = 64×(9×32+1) = 64×289 = 18,496 Output = ⌊(28+2-3)/1⌋+1=28 → shape 28×28×64 FC tương đương (25088→50176): 25088×50176 ≈ 1.26 tỷ → Conv dùng ít hơn 68,100× nhờ weight sharing!

5. Bài 2 — Cross-Corr vs True Conv (tính tay)

X=[[1,2,3],[0,1,2],[1,0,1]], W=[[1,0],[-1,2]], p=0,s=1 Output size: o=(3-2)/1+1=2 → 2×2 ─── Cross-Correlation (PyTorch, KHÔNG flip W) ─── (0,0): 1×1+2×0+0×(-1)+1×2 = 1+0+0+2 = 3 (0,1): 2×1+3×0+1×(-1)+2×2 = 2+0-1+4 = 5 (1,0): 0×1+1×0+1×(-1)+0×2 = 0+0-1+0 = -1 (1,1): 1×1+2×0+0×(-1)+1×2 = 1+0+0+2 = 3 → Y_xcorr = [[3,5],[-1,3]] ─── True Convolution (flip W 180° → [[2,-1],[0,1]]) ─── (0,0): 1×2+2×(-1)+0×0+1×1 = 2-2+0+1 = 1 (0,1): 2×2+3×(-1)+1×0+2×1 = 4-3+0+2 = 3 (1,0): 0×2+1×(-1)+1×0+0×1 = -1 (1,1): 1×2+2×(-1)+0×0+1×1 = 1 → Y_conv = [[1,3],[-1,1]] ≠ Y_xcorr!

Slide Example: X=4×4, W=3×3 (True Conv, p=0,s=1)

W=[[1,0,2],[1,2,0],[0,1,1]] → Rot180°=[[1,1,0],[0,2,1],[2,0,1]] X=[[3,1,0,1],[1,1,2,0],[1,2,2,1],[0,1,0,2]] o=(4-3)/1+1=2 → output 2×2: (0,0): [3,1,0,1,1,2,1,2,2]·[1,1,0,0,2,1,2,0,1] = 3+1+0+0+2+2+2+0+2 = 12 (0,1): [1,0,1,1,2,0,2,2,1]·[1,1,0,0,2,1,2,0,1] = 1+0+0+0+4+0+4+0+1 = 10 (1,0): [1,1,2,1,2,2,0,1,0]·[1,1,0,0,2,1,2,0,1] = 1+1+0+0+4+2+0+0+0 = 8 (1,1): [1,2,0,2,2,1,1,0,2]·... = 12 → Y = [[12,10],[8,12]]

8. Pooling Formulas

MaxPool: $o=\lfloor(i-k)/s\rfloor+1$;   2×2 s=2: $o=i/2$ (−½ mỗi chiều)
AvgPool: $Y(u,v)=\frac{1}{k^2}\sum_{i=0}^{k-1}\sum_{j=0}^{k-1}X(us+i,\;vs+j)$
GAP: $(H,W,C)\to C$ — 0 params, thay thế FC ở cuối (ResNet,EfficientNet)
Pooling KHÔNG có params; Max chỉ pass grad về vị trí max (gradient routing)

Bài 6 — MaxPool + AvgPool

Feature map 4×4: [[2,8,3,1],[6,4,7,5],[1,9,0,3],[4,2,8,6]] MaxPool 2×2 s=2: o=⌊(4-2)/2⌋+1=2 → 2×2: TL=max(2,8,6,4)=8 TR=max(3,1,7,5)=7 BL=max(1,9,4,2)=9 BR=max(0,3,8,6)=8 → [[8,7],[9,8]] AvgPool 2×2 s=2: TL=(2+8+6+4)/4=5.0 TR=(3+1+7+5)/4=4.0 BL=(1+9+4+2)/4=4.0 BR=(0+3+8+6)/4=4.25 → [[5,4],[4,4.25]]

9. Receptive Field / Dilated / Transposed

RF: $RF_1=k_1;\quad RF_n=RF_{n-1}+(k_n-1)\cdot\prod_{i=1}^{n-1}s_i$
2×Conv(k=3,s=1): $RF=3+(3-1)=5$  (= 1 Conv 5×5)
3 layers(k=3,s=2): $RF=3+(3-1)+(3-1)\cdot2\cdot2=3+2+8=13$
Dilated: $k_\text{eff}=d(k-1)+1$; k=3,d=2: $k_\text{eff}=5$
ASPP (DeepLab): $d\in\{1,6,12,18\}$ → multi-scale không ↓res
Transposed Conv: $o=(i-1)s-2p+k$  (decoder UNet, ×2 res với s=2,k=2)
Bilinear+Conv thay TransConv → tránh checkerboard artifact

10. Depthwise Separable / 2×(3×3) vs (5×5)

Standard Conv: $Kk^2D$ params
DW (per channel): $Dk^2$ + PW (1×1): $KD$ = $D(k^2+K)$
Ratio $=\frac{1}{K}+\frac{1}{k^2}$; k=3,K=64: $\frac{1}{64}+\frac{1}{9}\approx0.127$ (~8×, MobileNet)
2×Conv(3×3): $18D^2$ params; 1×Conv(5×5): $25D^2$ → tiết kiệm 28%
RF giống nhau (=5×5); 2×(3×3) có thêm 2 ReLU → phi tuyến mạnh hơn

YOLO 640px: $80^2+40^2+20^2=\mathbf{8\,400}$ anchors; FPN(top-down)+PAN(bottom-up)

ResNet skip: $y=\mathcal{F}(x,W)+x$;   $\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\left(1+\frac{\partial\mathcal{F}}{\partial x}\right)\geq1$ → no vanish
