📍 K-Nearest Neighbors (KNN) — Ch.3
▶ Nguyên tắc cốt lõi
  • Không tham số, lazy learning — ghi nhớ toàn bộ training data
  • Phân loại = majority vote của K điểm gần nhất
  • Không có giai đoạn "học" — toàn bộ chi phí ở test time
dist(x,x') = √Σ(xd - x'd)² [Euclidean — L2] dist(x,x') = Σ|xd - x'd| [Manhattan — L1]
▶ Brute Force vs KD-Tree vs Ball-Tree
Brute-force: O(N·D) mỗi query — duyệt tất cả N điểm, mỗi điểm O(D)
  • KD-Tree (phân hoạch siêu phẳng):
Build: chọn dim* = argmax_d Var(X_d), chia tại median → cây cân bằng, depth O(log N) Query: descent → backtrack với điều kiện prune: d(q, hyperplane) > r_best → bỏ toàn bộ subtree
⚡ Khi nào prune? Khi khoảng cách từ q đến siêu phẳng chia lớn hơn bán kính tìm kiếm hiện tại → mọi điểm trong subtree đều xa hơn best hiện tại.
  • Ball-Tree (phân hoạch hình cầu):
Mỗi node = một hình cầu (centroid c, radius r) Prune: d(q, centroid) − r > r_best → bỏ toàn cầu
Phương phápTốt khiKhông tốt khi
KD-TreeD thấp (≤20), N lớnD cao (curse of dim)
Ball-TreeD vừa, cluster dataD cực cao
⚠️ Curse of Dimensionality: D lớn → hypersphere query bao phủ toàn bộ hyperrectangle → pruning vô hiệu → cả cây phải duyệt. KD-Tree thoái hóa về O(N·D).
▶ Siêu tham số K
K=1: Train Err = 0 (self là nearest neighbor) Decision boundary = Voronoi cells K=N: predict majority class Train Err = n_minority/N = 1 − max_c P(c) K*≈√N: tối ưu (balance bias-variance)

✓ Train Err: monotone tăng với K. Test Err: U-shape. Chọn K bằng cross-validation.
▶ Quy trình thi
1
Tính khoảng cách từ query đến tất cả training points
2
Sắp xếp, lấy K điểm gần nhất
3
Majority vote → class label (hoặc mean → regression)
🔮 Naive Bayes — Ch.4
▶ Bayes Theorem — 4 thành phần
P(C|X) = P(C) · P(X|C) / P(X) ↑ ↑ ↑ ↑ Posterior Prior Likelihood Evidence
  • Prior P(C): tần suất lớp trong training data
  • Likelihood P(X|C): xác suất quan sát X khi biết lớp C
  • Evidence P(X): hằng số chuẩn hóa, không cần tính (argmax)
Log-Odds: log[P(+|X)/P(-|X)] = log[P(+)/P(-)] + Σk log[P(xk|+)/P(xk|-)] → Mỗi feature k đóng góp 1 "vote" độc lập
▶ Giả thiết Naive: Conditional Independence (CI)
P(X₁,...,Xn|C) = Π P(Xk|C) [CI definition] Tương đương: P(Xi|Xj,C) = P(Xi|C) ∀i≠j
Không có CICó CI (Naive)
2ⁿ−1 params/lớpn params/lớp
Cần data khổng lồEfficient, scalable
⚠️ Khi CI vi phạm: features tương quan → double-count evidence → posterior bị đẩy về 0 hoặc 1 (overconfident). VD: n features tương quan hoàn toàn → log-odds bị nhân n lần.
💡 CI thường vi phạm nhưng NB vẫn hoạt động tốt vì cần classify đúng, không cần probability chuẩn xác.
▶ Vấn đề Zero Frequency + Laplace Smoothing
Vấn đề: P(xk|c) = 0 → toàn bộ tích = 0 → mất hết thông tin Laplace: P(xk|c) = [count(xk,c) + α] / [count(c) + α·|V|]
✓ Laplace (α=1) = MAP với Dirichlet(1,...,1) prior. α là siêu tham số có thể tune.
▶ Multinomial NB cho Text
Generative story: 1. Chọn class: C ~ P(C) [prior] 2. Chọn độ dài: N ~ some dist 3. Mỗi từ i.i.d.: wt ~ P(w|C) [multinomial] Likelihood: P(d|c) ≈ Π P(wt|c) → underflow khi doc dài (10⁻⁶⁰⁰) Log-space: score(c) = log P(c) + Σt log P(wt|c) = log P(c) + Σk xk·log P(wk|c)

1
Tính log P(C) từ training data
2
Tính log P(xk|C) với Laplace smoothing
3
score(c) = log P(c) + Σk xk·log P(wk|c)
4
argmax_c score(c) → predicted class

🎯 K-Means Clustering
▶ Hàm mục tiêu WCSS
WCSS = Σk Σ_{x∈Ck} ‖x − μk‖² = "Tổng diện tích các hình vuông"
  • Không lồi (non-convex): không gian liên tục (μ) × rời rạc (C) → tổng không lồi
  • Global minimum là NP-hard → chỉ tìm được local minimum
▶ Lloyd's Algorithm
1
Init: Chọn K centroids μ₁,...,μK (ngẫu nhiên hoặc K-Means++)
2
Assignment: ci* = argmin_k ‖xi − μk‖² ← mỗi điểm → centroid gần nhất
3
Update: μk = (1/|Ck|) Σ_{xi∈Ck} xi ← centroid mới = mean của cluster
4
Lặp lại 2-3 cho đến khi không đổi
▶ Chứng minh Hội tụ (3 lập luận)
Lập luận 1 (Assignment): WCSS_after = Σ min_k‖xi−μk‖² ≤ WCSS_before ← mỗi xi chuyển sang centroid gần hơn hoặc bằng Lập luận 2 (Update): Mean = argmin_μ Σ_{xi∈Ck} ‖xi−μ‖² (tối thiểu toàn cục) ← đạo hàm = 0: dΣ/dμ = −2Σ(xi−μ) = 0 → μ* = mean Lập luận 3 (Hữu hạn): Số cấu hình ≤ K^N (hữu hạn) + WCSS monotone ↓ → KHÔNG thể lặp mãi → tất yếu hội tụ
⚠️ Đảm bảo: LOCAL minimum, không phải global. Chạy nhiều lần với init khác nhau.
▶ K-Means++ — Init thông minh
Seed: chọn centroids với P(x) ∝ d(x, nearest_centroid)² → Spread out các centroids ban đầu → E[WCSS] ≤ 8(ln K + 2) · WCSS* (guarantee)
▶ L2 → Mean | L1 → Median
L2: f(μ) = Σ‖xi−μ‖² df/dμ = −2Σ(xi−μ) = 0 → μ* = (1/n)Σxi = MEAN → Cân bằng signed distances (Σ(xi−μ) = 0) L1: g(μ) = Σ|xi−μ| [không khả vi tại xi] Subgradient: 0 ∈ ∂g/∂μ → #{xi>μ} = #{xi<μ} → μ* = MEDIAN → Cân bằng số lượng hai phía
MetricCenterCân bằng gìBreakdown
L2 (MSE)MeanSigned distances0% (outlier-sensitive)
L1 (MAE)MedianCounts50% (outlier-robust)
💡 D chiều: L1 và L2 đều tách theo từng tọa độ (separability) → áp dụng kết quả 1D độc lập cho mỗi chiều.
▶ Chọn K
  • Elbow method: vẽ WCSS vs K, tìm "khuỷu tay"
  • Silhouette score: (b−a)/max(a,b) ∈ [−1,1]
  • K-Means chỉ tìm cluster hình cầu — kém khi cluster kéo dài hoặc mật độ không đều
📈 Logistic Regression
▶ Logit → Sigmoid (Suy ra, không tùy tiện)
Bước 1: p ∈ (0,1) — bị giới hạn → không dùng trực tiếp Bước 2: Odds = p/(1-p) ∈ (0,+∞) Bước 3: Logit = log(p/(1-p)) ∈ (-∞,+∞) ← khớp với z z = w·x + b = log(p/(1-p)) Đảo ngược: p/(1-p) = eᶻ → p(1+eᶻ) = eᶻ → p = eᶻ/(1+eᶻ) = 1/(1+e⁻ᶻ) = σ(z)
σ(z) = 1/(1+e⁻ᶻ) σ(0) = 0.5 σ'(z) = σ(z)(1-σ(z)) ≤ 1/4 (max tại z=0)
💡 Sigmoid = NGHỊCH ĐẢO của Logit. Tên "Logistic Regression" xuất phát từ "logit".
▶ Cross-Entropy Loss = MLE
Bernoulli: P(y|x,w) = ŷʸ·(1-ŷ)^(1-y) CE = −log P(y|x,w) = −y·log ŷ − (1-y)·log(1-ŷ) → Minimize CE = Maximize Likelihood Gradient: ∂L_CE/∂z = ŷ − y ← SẠCH, không vanish (thừa số σ'(z) bị triệt tiêu hoàn toàn) Convexity: H = Σ σ(zi)(1-σ(zi)) xi xiᵀ ≽ 0 → Không có local minimum!
▶ MSE + Sigmoid = Gradient Vanishing
∂L_MSE/∂z = (ŷ−y)·σ'(z) = (ŷ−y)·ŷ(1-ŷ) Khi ŷ≈0 hoặc ŷ≈1: σ'(z)≈0 → gradient≈0 Nghịch lý: sai nhiều nhất → học ít nhất!
L lớp sigmoid: gradient ≤ (1/4)^L L=5 → 0.001, L=10 → 10⁻⁶ (gần như = 0)
⚠️ Deep network với sigmoid hidden layers: vanishing gradient → dùng ReLU thay thế.
▶ Precision / Recall / F1
Precision = TP/(TP+FP) "Trong những gì predict +, bao nhiêu đúng?" Recall = TP/(TP+FN) "Trong tất cả + thật, bao nhiêu được tìm?" F1 = 2PR/(P+R) [Harmonic mean — phạt mất cân bằng]

▶ Hard-Margin SVM
Support hyperplanes: H₁: w·x + b = +1 (lề lớp +1) H₂: w·x + b = −1 (lề lớp −1) Ràng buộc: yi(w·xi + b) ≥ 1 ∀i Bài toán tối ưu: min (1/2)‖w‖² s.t. yi(w·xi + b) ≥ 1 ∀i
▶ Chứng minh Margin = 2/‖w‖
Lấy x₊ ∈ H₁, x₋ ∈ H₂. Chiếu lên pháp tuyến ŵ = w/‖w‖: Margin = (x₊−x₋)·w/‖w‖ = (w·x₊ − w·x₋)/‖w‖ = (1−b−(−1−b))/‖w‖ = 2/‖w‖ Maximize margin = Minimize ‖w‖ = Minimize (1/2)‖w‖²
💡 Robustness: margin lớn → chịu được noise ε trong mọi hướng. Test point cần "vượt qua" margin mới bị phân loại sai.
▶ Khoảng cách điểm → siêu phẳng
dist(x₀, boundary) = |w·x₀ + b| / ‖w‖
▶ Quy trình thi — Tìm SVs, w, b, Margin
1
Identify SVs: điểm gần boundary nhất từ mỗi lớp
2
Lập hệ: yi(w·xi+b)=1 cho mỗi SV → D+1 phương trình
3
Giải: trừ các PT để khử b, tìm w, rồi tính b
4
Margin = 2/‖w‖. Kiểm tra: yi(w·xi+b) ≥ 1 ∀i
5
Predict: ŷ = sign(w·x+b)
▶ Dual Formulation
W(α) = Σαi − (1/2)Σij αiαj yi yj (xi·xj) max over α ≥ 0, Σ αi yi = 0 Nghiệm: w = Σ αi yi xi → Support vectors: αi > 0 (chỉ ~5-20% data) → Phần còn lại: αi = 0 → sparse solution
▶ Soft-Margin SVM — Siêu tham số C
min (1/2)‖w‖² + C·Σ ξi s.t. yi(w·xi+b) ≥ 1−ξi, ξi ≥ 0 ξi = 0: ngoài margin, đúng phía ✓ 0<ξi≤1: trong margin, đúng phía ✓ ξi = 1: trên decision boundary ξi > 1: sai phía = misclassified ✗

💡 C ≡ 1/λ trong regularization: C nhỏ ↔ λ lớn ↔ regularize mạnh ↔ underfit.
▶ Kernel Trick
Thay xi·xj → K(xi,xj) = φ(xi)·φ(xj) trong dual → Không cần tính φ(x) tường minh! Prediction: ŷ = sign(Σ αi yi K(xi,x) + b)
▶ RBF Kernel
K(x,x') = exp(−γ‖x−x'‖²) Gram matrix Kij = K(xi,xj), luôn PSD (positive semi-definite) Khi γ→0: Kij→1 mọi cặp → all-ones matrix → mọi điểm giống nhau → Linear SVM → Underfit Khi γ nhỏ: boundary mượt, ảnh hưởng rộng → generalize tốt Khi γ lớn: mỗi điểm = "đảo riêng" → overfit Khi γ→∞: Kij=0 (i≠j), Kii=1 → Identity I → Tương đương 1-NN → Train Err=0, Test Err cao
💡 γ = "bán kính ảnh hưởng nghịch đảo". RBF tương ứng với feature map vô hạn chiều (khai triển Taylor).

🌳 Decision Trees — Ch.5
▶ Độ đo tạp chất (Impurity)
Entropy: H(S) = −Σk pk·log₂(pk) Gini: G(S) = 1 − Σk pk² Error: E(S) = 1 − max_k pk Quan hệ: H ≥ G ≥ E (thường)
💡 Entropy nhạy cảm hơn Gini với splits cân bằng. CART dùng Gini vì tính toán nhanh hơn.
▶ Information Gain (ID3)
IG(S,A) = H(S) − Σv (|Sv|/|S|)·H(Sv) = H(parent) − Weighted H(children) Gain Ratio = IG(S,A) / SplitInfo(S,A) SplitInfo = −Σv (|Sv|/|S|)·log(|Sv|/|S|) → Sửa bias IG với attr nhiều values
▶ CART — Binary Splits
Gini split: chọn threshold t* = argmin_{t} [|L|/|S|·G(L) + |R|/|S|·G(R)]
▶ Overfitting & Pruning
  • Pre-pruning: max_depth, min_samples_split, min_impurity_decrease
  • Post-pruning: Reduced Error Pruning — cắt node nếu không tăng val accuracy
  • Cây sâu → overfit. Cây nông → underfit
✓ Interpretable, không cần normalize, xử lý cả categorical và numerical.
🧠 Neural Networks — Ch.7
▶ Forward Propagation
z^l = W^l · a^{l-1} + b^l a^l = σ(z^l) [activation function] Output: ŷ = softmax(z^L) hoặc σ(z^L)
▶ Backpropagation
δ^L = ∂L/∂z^L [output error] δ^l = (W^{l+1})ᵀ δ^{l+1} ⊙ σ'(z^l) [chain rule] ∂L/∂W^l = δ^l · (a^{l-1})ᵀ ∂L/∂b^l = δ^l
💡 ⊙ = element-wise product. Gradient flows backward, product tích lũy.

🔗 Hidden Markov Models
▶ 3 Ma trận tham số λ = (π, A, B)
π: P(q₁=i) [initial state probs] A: P(qt=j|qt-1=i) [transition matrix, N×N] B: P(ot=k|qt=i) [emission matrix, N×M]
▶ 3 Bài toán cơ bản
Bài toánInputThuật toán
EvaluationO, λ → P(O|λ)Forward α
DecodingO, λ → Q*Viterbi δ
LearningO → λ*Baum-Welch (EM)
▶ Forward Algorithm
αt(i) = P(o₁...ot, qt=i|λ) α₁(i) = πi · Bi(o₁) αt(j) = [Σi αt-1(i)·Aij] · Bj(ot) P(O|λ) = Σi αT(i)
▶ Viterbi Algorithm
δt(i) = max_{q₁...qt-1} P(q₁...qt=i,o₁...ot|λ) δ₁(i) = πi · Bi(o₁) δt(j) = [max_i δt-1(i)·Aij] · Bj(ot) Best path: backtrack từ argmax_i δT(i)
▶ Baum-Welch (EM)
γt(i) = P(qt=i|O,λ) [E-step] ξt(i,j) = P(qt=i,qt+1=j|O,λ) New Aij = Σt ξt(i,j) / Σt γt(i) [M-step] New Bi(k) = Σt:ot=k γt(i) / Σt γt(i)

⚔️ SVM — Chứng minh Margin = 2/‖w‖
Cho x₊ ∈ H₁: w·x₊+b=+1 x₋ ∈ H₂: w·x₋+b=−1 Vetor nối: v = x₊ − x₋ Chiếu lên ŵ = w/‖w‖: margin = v · ŵ = (x₊−x₋)·w/‖w‖ = (w·x₊ − w·x₋)/‖w‖ = ((1−b) − (−1−b))/‖w‖ = 2/‖w‖ ✓ Maximize 2/‖w‖ ⟺ Minimize ‖w‖ ⟺ Minimize (1/2)‖w‖² [convex, dễ đạo hàm]

📈 Logistic Reg — Chứng minh ∂L_CE/∂z = ŷ−y
L_CE = −y·log ŷ − (1−y)·log(1−ŷ), ŷ=σ(z) Bước 1 — ∂L/∂ŷ: ∂L/∂ŷ = −y/ŷ + (1−y)/(1−ŷ) Bước 2 — ∂ŷ/∂z: σ'(z) = σ(z)(1−σ(z)) = ŷ(1−ŷ) Bước 3 — Chain rule: ∂L/∂z = ∂L/∂ŷ · ∂ŷ/∂z = [−y/ŷ + (1−y)/(1−ŷ)] · ŷ(1−ŷ) = −y(1−ŷ) + (1−y)ŷ = −y + yŷ + ŷ − yŷ = ŷ − y ✓
✓ Thừa số σ'(z)=ŷ(1−ŷ) bị triệt tiêu hoàn toàn → gradient KHÔNG vanish.
So sánh MSE: ∂L_MSE/∂z = ∂[(ŷ−y)²/2]/∂z = (ŷ−y)·σ'(z) = (ŷ−y)·ŷ(1−ŷ) Khi ŷ→0: σ'→0 → gradient→0 (mặc dù sai nhiều) Khi ŷ→1: σ'→0 → gradient→0 (mặc dù sai nhiều) → NGHỊCH LÝ: sai nhiều → học ít ✗
📈 CE Convexity — Hessian ≽ 0
L_CE(w) = Σi [−yi log σ(zi) − (1−yi)log(1−σ(zi))] ∂²L/∂w² = Σi σ(zi)(1−σ(zi)) · xi xiᵀ = Σi ≥0 · PSD matrix → H = Σi σ(zi)(1−σ(zi)) xi xiᵀ ≽ 0 → L_CE là hàm CONVEX trong w → Không có local minimum → GD hội tụ global ✓
💡 PSD vì σ(z)(1−z)≥0 và xixi^T là ma trận rank-1 PSD. Tổng PSD là PSD.
