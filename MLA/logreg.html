Phân loại xác suất — nền tảng cho nhiều câu hỏi về threshold, loss functions, gradient.

1. Logit & Odds Ratio
\[ z = \mathbf{w}\cdot\mathbf{x}+b = \log\frac{P(y=1|\mathbf{x})}{P(y=0|\mathbf{x})} = \text{log-odds} \] \[ \text{Odds Ratio} = e^z, \quad \hat{y} = \sigma(z) = \frac{1}{1+e^{-z}} \]
Câu 8 — Tính Odds Ratio

Logit: \(z = \ln(3)\cdot X_1 - \ln(2)\cdot X_2\). Input \(X=[2,1]^\top\):

\[ z = \ln(3)\times 2 - \ln(2)\times 1 = 2\ln 3 - \ln 2 = \ln 9 - \ln 2 = \ln(4.5) \] \[ \text{Odds Ratio} = e^{\ln(4.5)} = \mathbf{4.5} \]

→ Đáp án: B. 4.5

5. Chứng minh Gradient Cross-Entropy — Tại sao sạch hơn MSE?
Đạo hàm Cross-Entropy theo logit z (bước từng bước)

Loss: \(L_{CE} = -y\log\hat{y} - (1-y)\log(1-\hat{y})\), với \(\hat{y}=\sigma(z)\), \(\sigma'(z)=\hat{y}(1-\hat{y})\).

\[ \frac{\partial L_{CE}}{\partial \hat{y}} = -\frac{y}{\hat{y}} + \frac{1-y}{1-\hat{y}} \] \[ \frac{\partial L_{CE}}{\partial z} = \frac{\partial L_{CE}}{\partial \hat{y}}\cdot\frac{\partial \hat{y}}{\partial z} = \left(-\frac{y}{\hat{y}}+\frac{1-y}{1-\hat{y}}\right)\cdot\hat{y}(1-\hat{y}) \] \[ = -y(1-\hat{y}) + (1-y)\hat{y} = \hat{y} - y \]
Kết quả: ∂L_CE/∂z = ŷ − y (chỉ là lỗi dự đoán!)
Thừa số sigmoid \(\hat{y}(1-\hat{y})\) từ chain rule triệt tiêu hoàn toàn với \(\frac{1}{\hat{y}(1-\hat{y})}\) từ đạo hàm CE → gradient không vanish. Mô hình học đều nhau bất kể output gần 0 hay 1.
6. Chứng minh MSE + Sigmoid → Gradient Vanishing
Đạo hàm MSE + Sigmoid — Nguyên nhân triệt tiêu

Loss: \(L_{MSE}=\frac{1}{2}(\hat{y}-y)^2\), \(\hat{y}=\sigma(z)\):

\[ \frac{\partial L_{MSE}}{\partial z} = (\hat{y}-y)\cdot\underbrace{\hat{y}(1-\hat{y})}_{\text{đạo hàm sigmoid}} \]

Khi nào dùng threshold thấp vs cao?
  • Recall ưu tiên (threshold thấp): Phát hiện ung thư, phát hiện gian lận — không bỏ sót ca bệnh dù có false alarm.
  • Precision ưu tiên (threshold cao): Spam filter — tránh block email quan trọng, OK nếu spam lọt qua đôi chút.
  • F1-Score: Khi cần cân bằng — không ưu tiên Precision hay Recall. Là mean điều hòa của hai độ đo.
8. L2 Regularization — Ý nghĩa Weight Decay và Điều chỉnh λ
Gradient Descent với L2 — Weight Decay step

Mục tiêu: \(L_{total} = L_{CE} + \frac{\lambda}{2}\|\mathbf{w}\|^2\). Gradient:

\[ \frac{\partial L_{total}}{\partial w_j} = \frac{\partial L_{CE}}{\partial w_j} + \lambda w_j \] \[ w_j \leftarrow w_j - \eta\!\left(\frac{\partial L_{CE}}{\partial w_j}+\lambda w_j\right) = \underbrace{(1-\eta\lambda)}_{\text{decay factor}} w_j - \eta\frac{\partial L_{CE}}{\partial w_j} \]

Hệ số \((1-\eta\lambda) < 1\) → trọng số bị "thu nhỏ" (decay) tại mỗi bước ngay cả khi loss gradient = 0 → trọng số lớn bị phạt mạnh → mô hình đơn giản hơn.

9. Ý nghĩa từng trọng số — Odds Ratio theo từng đặc trưng
Mỗi trọng số w_j là log(Odds Ratio) của đặc trưng x_j
\[ z = w_1 x_1 + w_2 x_2 + \cdots + w_D x_D + b \] \[ \text{Khi } x_j \text{ tăng 1 đơn vị} \Rightarrow z \text{ tăng } w_j \Rightarrow \text{Odds nhân thêm } e^{w_j} \] \[ \boxed{e^{w_j} = \text{Odds Ratio cho feature } x_j \text{ (per unit increase)}} \]
Ví dụ: Giải thích trọng số mô hình CustomerChurn

Giả sử mô hình Logistic Regression học được:

\[ z = 1.5 \cdot X_1(\text{SupportTickets}) - 0.08 \cdot X_2(\text{ServiceUsage}) + 0.3 \cdot X_3(\text{Discount}) - 2.0 \]
Featurew_je^{w_j} = ORDiễn giải
X1 SupportTickets+1.5e^1.5 ≈ 4.48Mỗi ticket thêm → odds churn tăng 4.48 lần
X2 ServiceUsage-0.08e^{-0.08} ≈ 0.923Mỗi đơn vị dùng thêm → odds churn giảm 7.7%
X3 DiscountApplied+0.3e^{0.3} ≈ 1.35Có discount → odds churn tăng 35%
Intercept b-2.0Base odds = e^{-2.0} ≈ 0.135Khi X1=X2=X3=0, odds churn ≈ 13.5%
Quy tắc dấu và độ lớn
  • w_j > 0: e^{w_j} > 1 → feature dương tính với lớp 1 (tăng odds)
  • w_j < 0: e^{w_j} < 1 → feature âm tính với lớp 1 (giảm odds)
  • |w_j| lớn: Feature có ảnh hưởng mạnh. L2-reg kéo các w_j về 0 → giảm OR cực đoan
Tính toán prediction đầy đủ từ x đến class

Dự đoán cho TS01: X1=4, X2=12, X3=0 (dùng mô hình trên):

\[ z = 1.5\times 4 + (-0.08)\times 12 + 0.3\times 0 + (-2.0) = 6.0 - 0.96 + 0 - 2.0 = 3.04 \] \[ \hat{y} = \sigma(z) = \frac{1}{1+e^{-3.04}} = \frac{1}{1+0.0477} \approx \mathbf{0.954} \] \[ \text{Odds} = e^{3.04} \approx 20.9 \quad\Rightarrow\quad \frac{P(\text{Churn})}{P(\text{No Churn})} = 20.9:1 \] \[ \text{Threshold } \theta=0.5: \hat{y}=0.954>0.5 \Rightarrow \textbf{Predict Churn (Yes)} \checkmark \]
