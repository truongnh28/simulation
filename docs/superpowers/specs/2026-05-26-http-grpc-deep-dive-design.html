7 SVG diagrams — http-deep-dive.html

  1. HTTP Evolution Timeline (top, sau page subtitle) — horizontal pipeline: HTTP/1.0 (1996) → HTTP/1.1 (1997) → HTTPS/TLS (2000s) → HTTP/2 (2015) → HTTP/3 (2022). Mỗi phase là box màu khác nhau. Anchor links đến sections tương ứng.
  2. s3 — Connection Models — 3-column SVG: HTTP/1.0 (serial, new conn each req), HTTP/1.1 pipelining (serial on 1 conn, HOL blocking), HTTP/2 multiplexing (parallel streams on 1 conn). Hiển thị timing bars.
  3. s5 — Request/Response Anatomy — 2-column SVG: trái = HTTP request (start-line, headers, blank line, body), phải = HTTP response. Highlight từng field với màu riêng.
  4. s12 — TLS 1.3 Handshake — sequence diagram 2 actors (Client/Server): ClientHello → ServerHello + EncryptedExtensions + Certificate + CertificateVerify + Finished → {Finished} → Application Data. Nhánh phụ: 0-RTT (early data).
  5. s13 — HTTP/2 Frame Layout — bit-level diagram (cùng style WS frame): 24-bit Length, 8-bit Type, 8-bit Flags, 1-bit Reserved + 31-bit Stream ID, Payload. Màu khác nhau cho từng field.
  6. s15 — HPACK Table — hiển thị static table (indexed 1–61) + dynamic table (FIFO eviction), mũi tên lookup flow: header field → check static → check dynamic → encode literal + insert dynamic.
  7. s18 — QUIC vs TCP Stack — 2-column SVG: trái = TCP+TLS+HTTP/2 layers (Application → HTTP/2 → TLS → TCP → IP), phải = QUIC+HTTP/3 (Application → HTTP/3 → QUIC [TLS integrated] → UDP → IP). Highlight latency reduction.
