3. Chat Room Demo

  • Server (server.js): Node.js http + ws@8, no Express. Connection registry Map<ws, {id,name,room}>, rooms Map<room, Set<ws>>, history Map<room, msg[]> (50 msgs max)
  • Client (index.html): Sidebar (room list, online users) + message area + typing indicator + file drop zone
  • Message types: join, message, private, typing, file-start, file-chunk (ArrayBuffer), file-end, history (server), presence (server), error (server)
  • File transfer: Binary frames, 16KB chunks, reassemble via Blob + URL.createObjectURL()
  • History: Server sends last 50 messages on join. Reconnect restores conversation.

4. Protocol Lab Demo

  • Server (server.js): Echo server + per-connection metrics (msg count, bytes, latency samples)
  • Frame Inspector panel: Shows each received/sent frame with FIN/opcode/mask/payload-len breakdown
  • Live Metrics panel: Throughput chart (msg/s, KB/s), latency histogram (RTT), text vs binary vs compressed comparison
  • Test modes: send text, send binary ArrayBuffer, send compressed (permessage-deflate), adjust message size + rate
