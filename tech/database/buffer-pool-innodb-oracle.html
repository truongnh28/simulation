🧮 Buffer Pool: InnoDB vs Oracle

So sanh kien truc Buffer Pool, LRU variants, Checkpoint va Flush mechanism trong hai he thong database hang dau

1. Vai Tro Cua Buffer Pool

Buffer Pool la thanh phan quan trong nhat cua bat ky RDBMS nao: cache cac data pages tren disk vao memory de tranh random I/O dat tien. Hieu nang cua database phu thuoc manh vao hit rate cua Buffer Pool.

Cac Loai Pages Trong Buffer Pool

  • Data Pages: B-Tree index pages
  • Undo Pages: Rollback segment pages
  • Insert Buffer Pages: Cho pending secondary index updates
  • Adaptive Hash Index: Hash index tu dong tren hot data
  • Lock Info: Lock bitmap pages

Key Parameters

  • innodb_buffer_pool_size: Kich thuoc Buffer Pool (nen 70-80% RAM)
  • innodb_buffer_pool_instances: So Buffer Pool instances (giam contention)
  • innodb_buffer_pool_chunk_size: Kich thuoc chunk (5.7.5+)

2. InnoDB Buffer Pool Architecture

2.1 LRU List — Toi Uu Voi Midpoint Insertion

InnoDB dung Modified LRU (khong phai LRU thuan tuy) de tranh viec full table scan lam mat di hot pages:

  • LRU list chia thanh 2 phan: Young (Hot) list (37%) o dau va Old (Cold) list (63%) o cuoi
  • Page moi duoc them vao midpoint (dau cua Old list), khong phai dau LRU
  • Neu page trong Old list duoc access sau innodb_old_blocks_time (mac dinh 1000ms) → chuyen len Young list
  • Full table scan: pages duoc them vao midpoint va nhanh chong bi evict ma khong lam mat Young pages

💡 Tai sao Midpoint Insertion?

Truong hop dien hinh: large table scan (mysqldump, OLAP query) doc hang trieu pages mot lan nhung sau do khong dung lai. Neu them vao dau LRU, se day het hot data ra. Midpoint insertion cho phep pages moi "chung minh" la hot truoc khi len Young list.

2.2 Flush List — Track Dirty Pages

Flush List la doubly-linked list chua tat ca dirty pages, sap xep theo oldest_modification LSN (pages duoc sua dau tien nam cuoi list). Day la basis cua Incremental Checkpoint.

2.3 Free List — Quan Ly Pages Ranh

Free List chua cac pages sach, san sang cho viec allocate. Khi can page moi: lay tu Free List → neu het → evict page cu tu LRU tail.

2.4 Page Cleaner Thread (MySQL 5.6+)

MySQL 5.6 gioi thieu page cleaner thread rieng biet de flush dirty pages ngoai master thread:

  • Adaptive flushing: tinh toan rate flush dua tren log generation rate
  • Tranh surge flushing (dot ngot flush nhieu) gay I/O spike
  • MySQL 5.7+ cho phep multiple page cleaner threads (innodb_page_cleaners)

3. Oracle Buffer Pool (Database Buffer Cache)

3.1 LRU va REPL List

Oracle dung kien truc phuc tap hon InnoDB:

  • Main List (MRU/LRU): Quan ly hot pages
  • Auxiliary List: Pages dang duoc xem xet evict
  • WRITE_MAIN / WRITE_AUX: Pages cho quan hang doi de write out
  • DBWR process: Database Writer process flush dirty pages (co the co nhieu DBWR)

3.2 Buffer Pool Phuc Tap Hon InnoDB

  • Oracle ho tro nhieu loai Buffer Pool: Default Pool, Keep Pool (giu cac hot objects), Recycle Pool (cho large one-time scans)
  • Cho phep DBA gan bang cu the vao pool cu the: ALTER TABLE t STORAGE (BUFFER_POOL KEEP)
  • Oracle Exadata co Smart Flash Cache them mot tang caching nua

5. InnoDB BP Dump/Restore (MySQL 5.6+)

Sau khi restart MySQL, Buffer Pool trong rong → warm-up period mat thoi gian. MySQL 5.6+ cho phep:

  • Dump: Ghi danh sach page identifiers (space_id, page_no) tu LRU list ra file
  • Restore: Doc file, sort cac page IDs (de dam bao sequential I/O), load pages vao Buffer Pool

✓ Random I/O → Sequential I/O

Viec sort page IDs truoc khi load chuyen warm-up tu random I/O (dat: 100-200 IOPS HDD) thanh sequential I/O (re: 100+ MB/s). Tren he thong lon, warm-up time giam tu hang gio xuong con vai phut.

6. Persistent Statistics (MySQL 5.6+)

MySQL 5.6 luu thong ke vao cac bang he thong thay vi chi giu trong memory:

  • mysql.innodb_table_stats: n_rows, clustered_index_size, sum_of_other_index_sizes
  • mysql.innodb_index_stats: n_diff, n_leaf_pages, size cua tung index

💡 Hack Execution Plan

Co the sua truc tiep bang thong ke de "dua" optimizer chon execution plan mong muon (dang biet plan tot hon optimizer). Nguy hiem nhung huu dung trong mot so truong hop khan cap production: UPDATE mysql.innodb_table_stats SET n_rows = ... roi FLUSH TABLE t.
